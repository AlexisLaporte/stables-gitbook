# Rareté du Look & des Items

Les NFTs de vrais chevaux ont un lien fort avec la réalité, car ils ont un jumeau du monde réel qui génère des points de manière passive, mais ils ont aussi leur propre existence dans le fantasy game.

Dans le jeu, les NFTs ont plusieurs composants :&#x20;

* leur look, qui peut être amélioré
* leur équipement (items) qui peut être amélioré&#x20;
* (à l'avenir) leurs capacités, appelées Horse Score&#x20;

Pour ce qui est du **look**, même si un NFT est un jumeau numérique d'un vrai cheval, ils ne se ressembleront pas. Le NFT est une représentation, c'est son avatar dans la simulation. Les looks ont été conçus par des artistes 3D de renom. Nous avons choisi de les représenter sous forme de figurines sur leur socle, impatientes de bouger et de courir.&#x20;

Chaque NFT a reçu un look et un équipement aléatoires, avec différents niveaux de rareté, détaillés ci-dessous.&#x20;

Les éléments et les capacités sont actuellement stockés dans notre base de données, mais nous avons l'intention de transférer certains actifs sur la blockchain, en particulier les éléments qui peuvent devenir eux-mêmes des NFT (et les NFT de cheval avec leurs items deviendraient ce qu'on appelle un NFT composable).

### Niveau d'équipement

| Level     | Rareté |
| --------- | ------ |
| Simple    | 66%    |
| Elaborate | 33%    |

Les équipements élaborés ajouteront des points à votre NFT dans les courses hybrides et virtuelles. \
\
Vous pourrez améliorer ou remplacer les équipements pour améliorer votre NFT, certains pouvant être temporaires ou cassables.
